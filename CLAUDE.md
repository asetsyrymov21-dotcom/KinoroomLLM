# Kinorum — инструкции для агента

## Навигация по проекту

Когда тебе нужно найти конкретный файл (модель, роутер, сервис, схему и т.д.) —
сначала прочитай `PROJECT_MAP.md` в корне проекта. Там есть полная карта с путями и описаниями.

Не читай PROJECT_MAP.md при каждом запросе — только когда нужна навигация по файлам.
